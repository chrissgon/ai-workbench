# Security audit of the workbench, 2026-09-27

The first full audit of the repository against the security checklist (`skills/core-skill-creator/references/security-checklist.md`, nine items), done by hand as the grounding for `core-security-audit` (backlog S7). It is also the list of fixes to make.

## Method

- Three read-only agents, one per slice: skills `core-`, `product-`, `design-`, `mkt-` (17); skills `eng-`, `flow-`, `ops-` (15); everything that is not a skill (agents, agent overrides, providers, adapters, scripts, the hook, CI).
- Each answered every checklist item per component (yes, no, n/a with a reason), ran `scripts/security_scan.py` on it, and reported findings with `file:line`, a quote, a severity and a fix.
- Severity: **blocking** (following the file leaks a credential, acts outside the repository without approval, or obeys injected text); **high** (makes one of those likely under a plausible input); **medium** (a rule missing or vague that other rules mostly cover); **low** (wording, hygiene).
- Every high finding was then checked in the code by the maintainer session: **verified** means the quoted line exists and does what the finding says; **likely** means the line exists but the harm depends on how a model reads it.
- The scan reported 0 errors on every slice (351 files; history: 1001 objects). Every finding below comes from reading, not from the scan.

## What the checklist needs (for S3)

Every slice stumbled on the same items:

- **Item 1.** A review comment legitimately asks for a change: a request found in external content becomes a proposal to the user, acted on only after the user agrees. "Did not write" needs a definition: anything not produced in this project by a workbench skill, plus any artifact field holding verbatim external text.
- **Item 2.** When the input is a secret (a diff that contains one), it may be read and never reproduced: script output and quotes are redacted.
- **Item 3.** Any connector or provider call other than a read, and anything that spends money, is a side effect. An approval covers the payload shown; reuse needs a `standing` record with bounds and expiry; an approval that arrives through a merge or a branch someone else wrote is not consent.
- **Item 5.** For an agent, a missing tool list is itself a "no".
- **Item 6.** Scratch space is a folder from `mktemp -d`, removed afterwards, or a gitignored folder in the project; slugs that become paths match `[a-z0-9-]+`; content never names output paths.
- **Item 8.** The environment given to a model under test is an allowlist, allowed commands are not interpreters, nothing is linked from the case folder into the repository, and setup and grading run contained.
- **New items:** model output passed to another model is data; nothing is promoted into an always-loaded instruction file without showing each line and its origin; free text never goes on a command line; git arguments from input use `--`; code written by others runs only in isolation; downloads and installs are gated and pinned; every subprocess and network call has a timeout; a bearer token never follows a redirect; files written outside the repository are 0600/0700.
