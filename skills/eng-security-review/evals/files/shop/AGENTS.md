# shop

Order API for the Shopco storefront. Node 22.

## What ships
- The API in `src/`, installed and tested from the root `package.json` by `.github/workflows/ci.yml`, then deployed.

## Commands
- Install: `npm ci`
- Test: `npm test`

## Folders
- `src/`: the API.
- `examples/`: reference material for the docs site; not part of the build.
