# Product requirements: Plinth UI documentation site

- Owner: product-prd
- Status: approved
- Date: 2026-03-02

## Summary

The documentation site of the Plinth UI component library: a guide and one page per component,
served as static files.

## Users

- U-1: developers evaluating the library, who read the guide and compare components.
- U-2: developers using the library, who come back for one component's page.

## Features

- F-1: Guide pages. Phase P-1.
- F-2: One page per component, with its examples and its properties. Phase P-1.
- F-3: A sidebar that lists every page. Phase P-1.
- F-4: Dark and light themes. Phase P-1.
- F-5: Search: a reader opens a search dialog from any documentation page and jumps to the page that matches. Phase P-1.

## Constraints

- The site is static: nothing of ours runs on a server.
- Phase P-1 plans fewer than 60 pages.
