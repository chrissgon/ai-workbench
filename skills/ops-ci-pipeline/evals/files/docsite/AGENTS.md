# docsite

Documentation site (Nuxt, static generation), hosted on Netlify at https://docs.example.dev (site name `example-docs`). Repository: github.com/example/docsite.

- Install: `npm ci`
- Checks: `npm run lint`, `npm run typecheck`, `npm run test` (unit tests, then Playwright over the generated site; run `npm run generate` first)
- One maintainer.
