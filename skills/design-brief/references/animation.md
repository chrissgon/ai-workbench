# Profile: animation (motion piece, animated demo, logo reveal, loader)

The Content section must contain:

- **Duration:** total length and whether it loops.
- **Timeline:** beats in order with their start time and length (for example 0.0–0.4 s the class `btn` types; 0.4–0.8 s the button gains its shape), each saying which claim it shows.
- **Final state:** the frame that remains when motion stops; it must carry the whole message on its own.
- **Reduced motion:** what is shown instead when the viewer prefers reduced motion (usually the final state).
- **Output:** format and size (CSS and HTML, Lottie, MP4, GIF), frame rate, file-size ceiling.

Criteria that matter for animations:

- Each beat demonstrates a claim; nothing moves for decoration only.
- Easing and durations consistent with the design system's motion rules.
- The final state alone carries the message.
- Loops without a visible jump, when it loops.
- Within the file-size ceiling; no flashing above three times per second.

Deliverables: round 1, a storyboard of key frames plus one working draft per direction; round 2, the final output in every requested format.
