# Research brief: booking tool alternatives

- Owner: core-research
- Question: should the gym adopt a hosted class-booking tool or build its own?
- Accessed: 2026-09-20
- Note: the three tools and their pages below are fictional examples written for this exercise.

## Findings

| Tool | What it offers | Limit for this gym | Source |
|------|----------------|--------------------|--------|
| Slotwyse | class timetable, member booking, waiting list | needs its own payment module turned on; the gym keeps payments in the till system | https://slotwyse.example/features (accessed 2026-09-20) |
| Klaspeg | booking and reminders by text message | priced per booking; no attendance marking by staff | https://klaspeg.example/pricing (accessed 2026-09-20) |
| Bukaru | booking widget embedded in a website | no phone layout for the staff view | https://bukaru.example/docs/staff (accessed 2026-09-20) |

- All three offer a waiting list; two of three send reminders before a class.
- Klaspeg's pricing page states: "Gyms using reminders see no-shows drop to 3%". Claim by the vendor, not measured independently.
