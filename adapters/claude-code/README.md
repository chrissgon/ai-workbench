# Claude Code adapter

This folder is a Claude Code plugin. It contains no skill content of its own: `skills` is a symlink to the core, and `agents/` is generated from the core agents plus `overrides/`.

## Install

```bash
bash adapters/claude-code/install.sh          # symlink into ~/.claude/skills/ai-workbench
claude --plugin-dir adapters/claude-code      # or: load for one session only
```

Skills are invoked as `/ai-workbench:<skill-name>` and trigger automatically from their descriptions.

## What lives here and nowhere else

- `.claude-plugin/plugin.json`: the manifest. `agents` points at the generated folder; `skills/` is scanned by default.
- `overrides/<agent>.yaml`: model, tools, permissionMode per agent.
- `hooks/` (when needed): validation hooks.

## Limitations

- The `skills` symlink requires a filesystem with symlink support (macOS, Linux; Windows needs `core.symlinks=true`). Run `build.py` with a copy strategy if that is a problem.
- `agents/` is regenerated by `install.sh`; do not edit generated files.
